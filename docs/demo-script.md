# Demo Script

## 60-second version

1. Open the app and point to the runtime panel.
2. Say: "This is Parallel Life Engine, a scrapbook generator for the lives you never lived."
3. Click one of the starter forks, ideally `Tokyo Photographer`.
4. Mention that the Gradio interface accepts either typed or spoken forks and streams the reconstruction progressively.
5. Start generation and narrate the reveal:
   "It first recovers the fork, then builds a decade-by-decade memoir, then layers portraits and timeline notes into a keepsake."
6. Show the recovered memoir title, timeline threads, and at least one portrait.
7. Click `Export Keepsake`.
8. Scroll to the replay shelf and open a previous run to show persistence.

## Key lines to say

- "This is not a chat answer. It is an alternate life artifact."
- "The smallest possible input becomes the richest possible keepsake."
- "The product is built as a chain of small specialist steps, which is why it fits Build Small."

## Safe fallback flow

If live generation is slow or unavailable:

1. Use the replay shelf.
2. Open a saved keepsake.
3. Explain that the same frontend also streams live runs when the runtime is active.
